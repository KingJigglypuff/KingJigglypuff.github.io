Project+Ex (This page is a work in progress)

WHAT IS PROJECT+EX?

Project+Ex (shortened to P+Ex) is an unofficial addon to Project+, which not only integrates the BrawlEx Clone Engine (which replaces the Project M Clone Engine), but also entirely new characters. P+Ex serves as a baseline build for others to build and branch off from. Or alternatively, just something to pick up and play


WHY USE P+EX?

When compared to other Ex-based builds, "Base P+Ex" aims to have a smaller, but higher quality selection of characters. P+Ex also tends to stay up-to-date with the latest Project+ releases whenever possible. If you wish to branch out to builds which add even more content, the most recognizable builds are the following: PMEX REMIX (discontinued), REX, Cobalt X, and PussPuss Build.


CHARACTERS

The current cast of character additions to P+Ex are the following: Ridley, Waluigi, Sceptile, and Dark Samus. You can learn more about them in detail through the navigation menu at the top of the page. Though note this website is a work in progress, so not everything will be available right away.


RESOURCES

For those wanting to customize P+Ex for their own purposes, BrawlInstaller is highly recommended. It's a powerful tool which allows users to add, remove, or manage characters, stages, music, and more.

Project+Ex is not an official project, nor does it intend to compete with official projects.
